# ADR-001：本地中文关键词检索基线

状态：已接受，用于当前实验阶段。

## 需求与约束

支持中文完整问题，返回有来源的片段。
目前使用本地 JSONL，不引入独立搜索服务。
保留现有子串检索，便于比较。

## 备选方案

- 手写匹配词数量排序：简单，但不能合理区分常见词和稀有词。
- jieba + rank-bm25：利用现成组件建立可测试的排序基线。
- 独立搜索服务：当前增加的部署成本较高。

## 决定

采用 jieba 进行中文分词，使用 rank-bm25 计算排序分数。
查询与文档使用一致的预处理。
原始文本、页号与字符位置保持不变。

## 验证方式

保持文档、分块、完整问题、目标证据和 K=5 不变，
比较子串检索与分词加 BM25 两条流程。

## 限制与复查条件

不保证解决同义表达、公式失真、跨块证据或自动拒答。
出现实测内存、索引时间或查询延迟瓶颈后，再评估搜索服务。
