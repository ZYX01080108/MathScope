# 子串检索基线 v0.1

## 配置

- 文档：lecture.pdf；文件指纹见 eval-draft.md
- 分块：500 字符，不跨页，无重叠
- 查询：eval_cases.json 中的完整问题
- 检索：去除查询两端空白，忽略大小写，匹配连续子串
- 返回顺序：文件顺序，无相关性排序
- 检查范围：前 5 条结果
