# MathScope 本地问答 MVP：交付与下一步

日期：2026-10-17（Asia/Shanghai）。这是本机单用户、单文档学习 MVP，不是公网产品。
本次把现有上传、解析、检索、已核对结论选择接口连成网页，不改原始 PDF、分块或核对登记。

## 1. 马上使用

入口是 http://127.0.0.1:8000/，不是开发者调试用的 /docs。
已有服务会立即读取新的 HTML/JS/CSS，但 Python 新路由必须重启才能加载。
如果左侧显示“模型状态未知 / HTTP 404”，不是需要重新上传文档，也不是密钥失效。
请在原来已设置 DeepSeek 环境变量的服务终端按 Ctrl+C，再从 D:\MathScope项目 启动：

```powershell
.\.venv\Scripts\python.exe -m uvicorn src.api:app --host 127.0.0.1 --port 8000
```

不要用 --reload 或多个 workers 来运行带本地调用次数限制的付费验收。
在原终端重启会保留该终端的环境变量；如果已关闭原终端，则需按 deepseek-guide.md
在服务器终端重新配置。密钥不填网页、不贴到对话、不进版本库。
重启会重置本机尝试计数，但不会取消平台费用，不能把重启当作无限续费额度。

## 2. 网页流程

1. 左侧选择已有的 lecture.pdf，不必重复上传或解析。其他 PDF 仍可上传、解析、检索。
2. 点击“三角不等式何时取等号？”示例，或输入自己的问题。示例按钮只填文字，不发请求。
3. 点击“免费预览证据”：先查原文，再查已核对注释，显示核对结论和 PDF 来源。
   这两次查询及模型状态读取都不调用 DeepSeek、不产生模型费用。
4. 预览状态 ready 且本机模型状态 ready 时，才允许勾选外发许可。明确勾选后点击
   “调用 DeepSeek 生成回答”，会发送本次问题和核对结论，可能收费。
5. 阅读真实回答、拒答或拦截原因；核对本次 model_called、模型名、token 用量及 PDF 引用。

页面不展示伪造的成功样例。预览不是回答，查不到核对结论也不证明原讲义没有答案。
没有可用核对结论时直接停在本地预览，不请求模型；这不是已经观察到模型的拒答。
有结论却要求完整证明时，模型仍可能调用后拒答，并可能收费。

当前没有任意讲义的通用已核对知识库：登记 FR001 只覆盖固定 lecture.pdf 的一条
三角不等式取等号结论，不能把这条记录强行套到其他问题或文件。页面可阅读原文，但
数学公式提取仍可能损坏，不会因此解除后端风险保护，也不自动补造证明。

## 3. 编号、费用和错误保护

- 页面保存免费预览的 reviewed_context_id，调用时自动填 expected_reviewed_context_id。
  用户不必复制哈希。问题、文档、K 或检索方案变化后，旧预览与许可失效。
- 后端仍在模型调用前检查版本。409 不会自动删掉保护参数、自动换证据或自动重试。
- 每次回答尝试发出前即消费本次预览和许可；无论成功失败，再调用都要重新预览并同意。
- 页面锁定进行中的操作，禁止重复点击。没有自动调用、自动重试、后台轮询付费接口。
- 网络或响应检查错误可能发生在调用之后，不能保证免费；先看提示和平台账单。
- calls_used/max_calls 是当前服务实例的保守尝试计数，不是账户总次数或人民币硬预算。
- GET /generation-status 是第 15 个业务操作，返回 provider、model、本机状态和计数。
  不返回密钥、不验证凭证或余额、不调用上游。响应及前端请求均禁止缓存。
- 左侧“本机配置就绪”不代表密钥有效或余额充足；只有实际回答响应才描述本次调用。

模型状态包括 disabled、missing_key、busy、limit_reached、ready。状态未知或不可用时
付费按钮禁用，免费检索和预览仍可使用。密钥始终只在服务器进程内使用。

不增加 npm 或 Python 依赖；不改检索算法、数据目录、原始提取文本或核对注释。
不自动提交 Git，不移动 backend-v0.1 标签，不发布讲义、代码或密钥到外部平台。

## 6. 后面的工作

现在已经有“可操作的本地学习 MVP”，后续按目的区分，而不是全部堆到这一步：

1. 真实小额验收：重启加载新后端，网页跑一题应回答、一题应拒答，查看引用和平台费用；
   或显式运行六题开发评测。不能把模拟测试通过当作模型已经答对。
2. 扩大证据覆盖：增加人工核对的定理和题目、更多独立文档，建立留出测试集；
   改善公式提取/OCR 和审阅工作流，不把风险文本当可靠公式。
3. 提高检索和回答质量：在独立评测上比较语义/混合检索与重排、验证结论支持和拒答理由，
   保留来源与费用保护后再增加推导能力。
4. 面向他人使用：持久化全局费用预算、用户隔离与权限、后台解析任务、日志和备份、
   滥用限制与部署保护。当前不具备这些条件，不直接开放到公网。

历史固定十题检索评测、当前六题回答开发评测和网页验收是不同层次；它们互相补充，
不能单靠一个“通过率”宣称整个系统数学正确。
